8. Troubleshooting

Diagnose and fix common training and deployment problems.

On this page

  • Overfitting
  • Underfitting
  • Instabilities
  • Utilization

Overfitting

  • Increase augmentation; add dropout or weight decay.
  • Gather more data or use mixup/cutmix.
  • Early stopping and ensembling.

Underfitting

  • Increase model capacity or train longer.
  • Reduce regularization/augmentation strength.
  • Tune learning rate and schedule.

Instabilities

  • Lower the learning rate; use gradient clipping.
  • Check initialization and normalization placements.
  • Inspect data (labels, corrupt images) and loss for NaNs.

Low Utilization

  • Increase DataLoader workers; use pinned memory and prefetching.
  • Ensure I/O isn’t the bottleneck; cache decoded datasets.
  • Use mixed precision and larger batches if memory allows.
