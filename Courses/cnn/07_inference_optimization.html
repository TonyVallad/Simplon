7. Inference & Optimization

Make CNNs fast, small, and reliable for deployment.

On this page

  • Export
  • Quantization
  • Pruning
  • Distillation
  • Serving

Export

Export to ONNX or TorchScript to run on different runtimes and hardware.

Quantization

Use dynamic or static quantization to reduce model size and improve latency. Calibration data is needed for static quantization.

Pruning

Remove unimportant weights or channels; fine-tune afterward to recover accuracy.

Distillation

Train a smaller student model using soft targets from a larger teacher.

Serving

  • Batch for throughput vs latency trade-offs.
  • Cache preprocessed inputs and frequent results.
  • Monitor drift and performance; add canaries for safe rollouts.
