5. Vision Tasks (Cls/Det/Seg)

How to adapt CNNs to common vision tasks and measure performance.

On this page

  • Classification
  • Object Detection
  • Semantic Segmentation
  • Evaluation

Classification

Add a global pooling head and a linear classifier. Use label smoothing and balanced sampling if classes are imbalanced.

Object Detection

  • Two-stage (Faster R-CNN): region proposals then classification/regression.
  • One-stage (RetinaNet/YOLO): directly predict classes and boxes.

Backbone CNN extracts features; FPN adds multi-scale features.

Semantic Segmentation

U-Net: encoder–decoder with skip connections; DeepLab: atrous/dilated convolutions and ASPP for larger context.

Evaluation

  • Classification: accuracy, F1, ROC/PR AUC.
  • Detection: mAP across IoU thresholds; per-class AP.
  • Segmentation: IoU/Jaccard, Dice, per-class metrics.
