Pooling

Max/Avg pooling reduce spatial size. Global average pooling collapses H×W to 1×1 by averaging.

gap = nn.AdaptiveAvgPool2d((1,1))

Normalization

BatchNorm is common in CNNs; GroupNorm is batch-size agnostic.

bn = nn.BatchNorm2d(64)
gn = nn.GroupNorm(num_groups=32, num_channels=64)

Activations

ReLU is the workhorse; SiLU/GELU are smooth alternatives that often improve accuracy.

Residual Blocks

# Basic ResNet block (sketch)
class BasicBlock(nn.Module):
  def __init__(self, c: int):
    super().__init__()
    self.conv1 = nn.Conv2d(c, c, 3, padding=1)
    self.bn1 = nn.BatchNorm2d(c)
    self.conv2 = nn.Conv2d(c, c, 3, padding=1)
    self.bn2 = nn.BatchNorm2d(c)
    self.act = nn.ReLU(inplace=True)
  def forward(self, x):
    h = self.act(self.bn1(self.conv1(x)))
    h = self.bn2(self.conv2(h))
    return self.act(x + h)

Depthwise Separable

Depthwise conv per channel followed by pointwise 1×1 conv reduces parameters and compute (MobileNet).

# Depthwise + Pointwise
dw = nn.Conv2d(64, 64, 3, padding=1, groups=64)
pw = nn.Conv2d(64, 128, 1)
