Convolution vs Correlation

In deep learning libraries, “convolution” is typically implemented as cross-correlation: the kernel is not flipped. This choice does not affect learning since the kernel is learned.

# PyTorch: 2D convolution layer
import torch.nn as nn
conv = nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3, stride=1, padding=1)

Kernels & Feature Maps

A kernel (filter) slides across the input computing a weighted sum. Each kernel produces one feature map. Stacking many kernels yields many feature maps capturing different patterns (edges, textures, shapes).

  • Channels: input channels are combined by the kernel; output channels equal number of filters.
  • Parameter sharing: the same kernel weights apply at all spatial locations.

Padding, Stride, Dilation

  • Padding controls border handling; same padding keeps spatial size.
  • Stride controls step size; larger stride downsamples.
  • Dilation spaces kernel elements; enlarges receptive field without extra params.

# H_out = floor((H_in + 2P - D(K-1) - 1)/S + 1)

Receptive Fields

Stacking layers increases the receptive field—the input region that affects an output unit. Pooling, stride, and dilation all expand the receptive field.
