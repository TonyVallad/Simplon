3. Types of Layers

Understand the building blocks: what they do, how they work, and when to use them.

Dense

Applies an affine transform y = Wx + b, followed by an activation. Parameter count equals inputs × outputs + outputs.

  • Use: tabular, output heads, feature projections.
  • Pitfalls: large matrices → overfitting; mitigate with dropout/regularization.
# PyTorch: a simple dense block
import torch.nn as nn
dense_block = nn.Sequential(
  nn.Linear(128, 256), nn.ReLU(), nn.Dropout(0.2),
  nn.Linear(256, 64), nn.ReLU()
)

Convolution

Local receptive fields with shared weights. Hyperparameters: kernel size, stride, padding, dilation, filters.

Standard

Kernel spans all input channels; outputs sum channel-wise responses.

Depthwise separable

Depthwise conv per channel + pointwise 1×1 conv; parameter-efficient.

Dilated

Spaces kernel taps to enlarge receptive field without pooling.

# PyTorch: a small CNN stem
cnn = nn.Sequential(
  nn.Conv2d(3, 32, kernel_size=3, padding=1), nn.ReLU(),
  nn.Conv2d(32, 64, kernel_size=3, padding=1), nn.ReLU(),
  nn.MaxPool2d(2)
)

Pooling

Downsamples features by aggregating neighborhoods. Max pooling retains strongest responses; average pooling smooths.

Recurrent

RNN, LSTM, GRU maintain hidden state hₜ. LSTM gates (input/forget/output) control information flow; GRU simplifies with update/reset gates.

# PyTorch: bidirectional GRU
rnn = nn.GRU(input_size=128, hidden_size=64, num_layers=2, batch_first=True, bidirectional=True)

Normalization

  • BatchNorm: stabilize and speed training; depends on batch statistics.
  • LayerNorm: per example; common in transformers; batch-size agnostic.
  • Group/InstanceNorm: helpful for style transfer, small-batch conv-nets.
# PyTorch: BatchNorm and LayerNorm examples
bn = nn.BatchNorm2d(num_features=64)
ln = nn.LayerNorm(normalized_shape=128)

Dropout

Randomly zero activations at training; scales activations at inference. Reduces co-adaptation and overfitting.

Attention

Computes weights from queries and keys, and mixes values accordingly. Multi-head attention attends to different subspaces.

# PyTorch: MultiheadAttention (sequence length L, embedding d)
attn = nn.MultiheadAttention(embed_dim=256, num_heads=4, batch_first=True)
context, weights = attn(query=X, key=X, value=X)

Embedding

Learned lookup table mapping discrete IDs to dense vectors. For NLP tokens, categories, or user/item IDs.

# PyTorch: token embedding
embed = nn.Embedding(num_embeddings=vocab_size, embedding_dim=256)
X_emb = embed(X_token_ids)

Residual

Skip connections add input to output of a block, improving gradient flow and enabling very deep architectures.

# PyTorch: a simple residual block
class ResBlock(nn.Module):
  def __init__(self, d: int):
    super().__init__()
    self.net = nn.Sequential(nn.Linear(d, d), nn.ReLU(), nn.Linear(d, d))
    self.act = nn.ReLU()
  def forward(self, x):
    return self.act(x + self.net(x))

Activations

  • ReLU: fast, sparse activations; can "die" with large negative inputs.
  • Leaky ReLU / PReLU: mitigate dead neurons with small negative slope.
  • GELU / SiLU: smooth; commonly used in transformers/CNNs.

Positional Encoding

Transformers lack recurrence/convolution; add position information via sinusoidal or learned encodings to preserve order.
