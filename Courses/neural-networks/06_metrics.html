Classification

  • Accuracy: fraction of correct predictions; misleading for imbalanced data.
  • Precision: TP / (TP + FP).
  • Recall: TP / (TP + FN).
  • F1: harmonic mean of precision and recall.
  • ROC AUC: threshold-independent; insensitive to class imbalance.
  • PR AUC: preferred for rare positives.
  • Top-k accuracy for multi-class with large label sets.
# scikit-learn: metrics example
from sklearn.metrics import precision_recall_fscore_support, roc_auc_score
prec, rec, f1, _ = precision_recall_fscore_support(y_true, y_pred, average='binary')
roc = roc_auc_score(y_true, y_score)  # y_score are probabilities/logits

Regression

  • MAE: median-friendly; interpretable in target units.
  • MSE / RMSE: penalize large errors more; RMSE in original units.
  • R²: variance explained; beware over-optimism with leakage.
  • MAPE: relative error; unstable near zero.

Segmentation & Detection

  • IoU/Jaccard and Dice for segmentation overlap.
  • mAP across IoU thresholds summarizes detection performance.

Calibration

Well-calibrated probabilities match observed frequencies. Use reliability diagrams, Brier score; apply temperature scaling or isotonic regression to fix miscalibration.

# Temperature scaling (sketch)
import torch.nn as nn
class TemperatureScaler(nn.Module):
  def __init__(self):
    super().__init__(); self.t = nn.Parameter(torch.ones(()))
  def forward(self, logits):
    return logits / self.t.clamp_min(1e-6)

Thresholding

Choose a decision threshold that optimizes the business-relevant trade-off (e.g., Youden’s J, F1-max, cost-sensitive thresholds). Evaluate stability across datasets.

# Find F1-max threshold
import numpy as np
from sklearn.metrics import f1_score

def best_threshold(y_true, y_score):
  thresholds = np.linspace(0, 1, 201)
  scores = [f1_score(y_true, y_score >= t) for t in thresholds]
  return thresholds[int(np.argmax(scores))]
