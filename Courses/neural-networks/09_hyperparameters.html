9. Hyperparameter Tuning

Systematic exploration to find robust, performant settings.

On this page

  • Search Methods
  • Key Hyperparameters
  • Protocol

Search Methods

  • Random search: better coverage than grid for the same budget.
  • Bayesian: models the response surface to pick promising trials.
  • Hyperband/ASHA: early-stop underperformers to save compute.

Key Hyperparameters

  • Learning rate and schedule.
  • Batch size; accumulation to emulate larger batches.
  • Model depth/width; dropout rate; weight decay.
  • Augmentation strengths; label smoothing; mixup/cutmix.

Protocol

  1. Start with a simple, fast baseline.
  2. Find a good LR via range test; set schedule.
  3. Increase capacity; add regularization as needed.
  4. Tune the most sensitive knobs; measure on validation.
  5. Lock the protocol; one final test evaluation.
