11. Practical Checklist

High-signal steps to avoid common pitfalls.

On this page

  • Data
  • Baselines
  • Training
  • Evaluation
  • Reproducibility

Data

  • Clean labels; deduplicate; handle missing and outliers.
  • Define stratified/group/time-aware splits; freeze them.
  • Document preprocessing and augmentations.

Baselines

  • Simple baseline (e.g., logistic regression) for reference.
  • Non-neural baselines for tabular tasks (GBDT) if applicable.

Training

  • Run LR range test; set schedule.
  • Use appropriate initialization and normalization.
  • Enable mixed precision; monitor gradient norms.
  • Checkpoint best and last; enable early stopping.

Evaluation

  • Pick metrics aligned with costs; include PR AUC if positives are rare.
  • Plot curves (ROC/PR), calibration, and confusion matrices.
  • Error analysis: slice by cohorts; inspect failure cases.

Reproducibility

  • Fix seeds; log configs, versions, and git commit.
  • Save data split indices and preprocessing artifacts.
