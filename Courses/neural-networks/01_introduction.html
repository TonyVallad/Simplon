What is a Neural Network?

A neural network is a composition of simple functions (layers) that transforms inputs into outputs. Each layer applies a linear transformation followed by a non-linear activation. Stacking layers yields highly expressive models able to approximate complex functions.

Intuition: Layers gradually transform raw inputs into progressively more useful representations for the task.

Perceptron

A perceptron computes a weighted sum of inputs plus a bias, then applies an activation. With linear activation, it models linear decision boundaries. With non-linear activations and layered composition, we get the building block of modern deep nets.

Non-linearity

Without non-linear activations, stacked linear layers collapse to a single linear transform. Popular choices include ReLU, GELU, and SiLU. Non-linearities enable deep networks to model complex, curved decision boundaries.

Universal Approximation

With sufficient width, a single hidden layer MLP can approximate any continuous function on a compact set. Depth improves parameter efficiency, allowing complex functions to be represented with fewer parameters than very wide shallow networks.

Note: Universal approximation guarantees existence, not that gradient descent will find it with finite data and compute.

Loss Functions

  • MSE for regression; sensitive to outliers.
  • MAE for robust regression.
  • Cross-entropy for classification with softmax/sigmoid outputs.
  • Focal loss for class imbalance and hard examples.

Backpropagation

Efficiently computes gradients via the chain rule in reverse. Autodiff libraries (e.g., PyTorch) implement this. Combined with stochastic optimization, this enables training at scale.

A tiny working example

Train a small MLP to learn XOR, a classic non-linear function.

import torch
import torch.nn as nn

X = torch.tensor([[0.,0.],[0.,1.],[1.,0.],[1.,1.]])
y = torch.tensor([[0.],[1.],[1.],[0.]])

model = nn.Sequential(
  nn.Linear(2, 8), nn.ReLU(),
  nn.Linear(8, 1), nn.Sigmoid()
)

opt = torch.optim.Adam(model.parameters(), lr=0.05)
loss_fn = nn.BCELoss()

for epoch in range(2000):
  opt.zero_grad()
  y_hat = model(X)
  loss = loss_fn(y_hat, y)
  loss.backward()
  opt.step()

print(torch.round(model(X)).view(-1).tolist())  # ≈ [0., 1., 1., 0.]

Parameters vs Hyperparameters

  • Parameters: learned by the optimizer (weights, biases, embeddings, etc.).
  • Hyperparameters: chosen by you (learning rate, batch size, depth, dropout rate).

Training vs Inference mode

Some layers behave differently at training vs inference (e.g., Dropout, BatchNorm). Switch with model.train() and model.eval().
