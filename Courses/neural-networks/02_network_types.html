2. Types of Neural Networks

Choosing the right architecture gives your model a head start by matching the structure of the data.

Multilayer Perceptron (MLP)

Fully connected layers; universal approximators of continuous functions with enough width. Best for tabular or vector inputs without explicit spatial/temporal structure.

  • Strengths: simple, fast to iterate; strong on tabular with good features.
  • Limitations: parameter heavy for high-dimensional inputs; ignores locality and order.
  • Typical uses: credit risk, churn prediction, structured data tasks.
  • Example: 3-layer MLP for tabular classification: Dense(128) → ReLU → Dense(64) → ReLU → Dense(C).

Convolutional Neural Networks (CNN)

Convolutions encode spatial locality and translational invariance. Shared kernels scan over inputs to produce feature maps capturing edges, textures, and higher-level patterns.

  • Strengths: parameter efficiency; excellent for images and signals.
  • Limitations: global context requires deeper networks or attention.
  • Tricks: batch norm + ReLU, residual blocks, depthwise separable convs.
  • Example: Conv(32, 3×3) → ReLU → Conv(64, 3×3) → ReLU → MaxPool → Dense.

Recurrent Networks (RNN, LSTM, GRU)

Sequence models with recurrent connections carry information across time. LSTM/GRU use gates to preserve long-term dependencies.

  • Strengths: effective for moderate-length sequences; compact state.
  • Limitations: sequential computation limits parallelism; long contexts are hard.
  • Variants: bidirectional RNNs, stacked layers, attention-augmented.
  • Example: BiLSTM(128) → Dropout(0.3) → Dense for token/class labeling.

Transformers

Self-attention relates all tokens in a sequence in parallel, enabling long-range dependencies and scalability with modern hardware.

  • Strengths: state-of-the-art across NLP, vision, speech; parallelizable.
  • Limitations: vanilla attention has quadratic cost in sequence length.
  • Patterns: multi-head attention, residuals + layer norm, feed-forward blocks.
  • Example: [Embedding] → [Positional] → N×(MH-Attn → FFN) → Pool → Head.

Graph Neural Networks (GNN)

Message passing layers aggregate and transform neighbor features, allowing learning on arbitrary graph structures.

  • Strengths: handles non-Euclidean domains (molecules, social, knowledge graphs).
  • Limitations: over-smoothing in deep stacks; scaling to massive graphs.
  • Example: GraphConv → ReLU → GraphConv → GlobalPool → Dense.

Autoencoders

Encoder maps inputs to a low-dimensional latent; decoder reconstructs. Useful for compression, denoising, and anomaly detection. Variational autoencoders (VAE) model a latent distribution.

  • Example: Conv → Conv → Bottleneck (z) → Deconv → Deconv → Reconstruction.

Generative Adversarial Networks (GANs)

Two-player game: generator creates synthetic samples; discriminator distinguishes real vs fake. Training dynamics are delicate but can yield highly realistic outputs.

  • Example: DCGAN with transposed convolutions for image synthesis.
  • Tip: use spectral norm or gradient penalty to stabilize discriminator.
